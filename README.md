Site estático responsivo em HTML, CSS e JavaScript.

## Como visualizar
Abra `index.html` no navegador ou publique a pasta em Vercel, Netlify ou GitHub Pages.

## Antes de publicar comercialmente
- Confirme que a autorização comercial cobre a distribuição e a publicidade da obra e de sua capa.
- Substitua os espaços de depoimentos por avaliações reais, com autorização dos autores.
- Confirme na Hotmart o formato, preço, prazo de entrega, garantia e demais condições da oferta. O site não promete condições ainda não cadastradas.
- A capa exibida é uma representação gráfica criada para esta página, não uma reprodução da capa editorial original.

## Arte de capa
O arquivo `assets/capa-o-corpo-fala.svg` é uma proposta gráfica original para divulgação. Não substitui a capa editorial oficial da obra. Confira os direitos de uso da capa original antes de anunciar a edição.
